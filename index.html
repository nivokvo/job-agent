How it works

  1. A launchd daemon polls a local job board every minute on weekdays, and LinkedIn, Himalayas, Remote OK and the Hacker News hiring thread every few hours.
  2. A cheap model filters first. Claude Opus scores the survivors against one rules file and writes the cover letter.
  3. A headless browser applies. On LinkedIn, Claude Sonnet fills the Easy Apply form page by page and stops if a question needs a fact it doesn't have.
  4. Recruiter replies go through Opus and a second model that checks for invented facts. The agent sends at most 3 messages per chat on its own. An interview, a test task or an offer goes straight to me in Telegram.
  5. When the laptop sleeps, a Cloudflare Worker and GitHub Actions keep going. Captchas are never solved: the agent backs off and tries later.

So far it has sent … recruiter replies on its own and handed … chats over to me.
